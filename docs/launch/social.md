## LinkedIn

### Variant 1 — Practitioner framing

**Introducing GRADE: an open benchmark for AI in education program analytics**

When educators and program managers use AI to analyze tutoring program data, the stakes
are real. Whether a model correctly reads an attendance trend, appropriately caveats a
small-subgroup finding, or avoids fabricating a causal claim can affect decisions that
directly impact students.

General-purpose AI benchmarks don't measure this. GRADE does.

GRADE — Grounded Reasoning and Analysis for Data in Education — is an open benchmark
covering 26 tasks across five analytical tracks:

1. Grounded retrieval and computation
2. Program snapshot and trend interpretation
3. Operational coaching and recommendations
4. Equity and subgroup interpretation
5. Program effectiveness and research reasoning

All tasks run against fully synthetic, seeded tutoring-program fixtures. Responses are
scored on six dimensions including grounding accuracy, evidence linkage, and calibration
and limitation handling.

The benchmark, runner, fixtures, and scoring code are open-source under Apache 2.0.

Learn more and run the benchmark: github.com/PearlEng/<NAME>

### Variant 2 — Research and developer framing

**GRADE: open benchmark for AI in education program analytics**

We're releasing GRADE, a reproducible, open-source benchmark for evaluating AI systems
on education program analytics tasks.

**What it measures:**
- Can the model retrieve and compute facts accurately from structured program data?
- Does it produce calibrated trend summaries without fabricating causal claims?
- Does it handle equity and subgroup data responsibly, including correct suppression of
  low-N groups?
- Can it synthesize local program observations with published research findings?

**How it works:**
- 26 tasks across 5 tracks, all backed by synthetic tutoring-program fixtures
- 5 repeated runs per (model × task) for consistency measurement
- Six scoring dimensions with locked weights and explicit per-task rubrics
- Ground-truth validated gold facts for automated fact scoring

**Open-source:**
- Apache 2.0 license
- Generic runner + OpenRouter adapter
- Task schema, fixture schema, and scoring code all public
